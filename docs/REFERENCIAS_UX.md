# Referências de interface e rotina

## BJJ Control — pesquisa inicial em 27/10/2026

O usuário informou que a academia usa BJJ CONTROL e quer utilizá-lo como referência de simplicidade para evoluir Tatame. Foram consultadas páginas públicas oficiais:

- [Site oficial](https://bjjcontrol.com.br/).
- [Painel web, página de login](https://app.bjjcontrol.com.br/bjjcontrol/).
- [Aplicativo de alunos no Google Play](https://play.google.com/store/apps/details?id=br.com.connectas.bjjcontrol).
- [Aplicativo de professores no Google Play](https://play.google.com/store/apps/details?id=br.com.connectas.bjjcontrol.professores).

Nenhuma área autenticada foi acessada, conta trial criada ou credencial enviada. Descrições comerciais não são prova de operação das funções. Para comparação do fluxo usado pela academia, falta uma gravação/screenshots fornecidos pelo usuário ou a versão web aberta com login feito por ele. A pesquisa não autoriza importar dados, mudar configurações ou enviar mensagens no serviço externo.

As decisões já implementadas nesta rodada vieram dos pedidos e imagens do usuário: menos campos na graduação; categorias explícitas; comunicados em menu próprio; controles de planos opcionais; distinção de consumo de plano e treinos realizados. Não foram atribuídas a uma análise privada do concorrente.

## Referências recebidas depois — ranking e presença

O usuário forneceu quatro screenshots do uso do BJJ Control, com ranking geral/mensal, pódio/fotos e lista de presença por dia/horário. Essas imagens embasaram os novos fluxos do Tatame; não implicam acesso à área privada do serviço. Implementação própria mantém o visual do Tatame, regras de confirmação existentes, fotos próprias, ranking geral/mensal e navegação de dia/aula. Não foram copiadas fotos de terceiros, nomes reais, marca nem dados do concorrente. Provas usam somente dados fictícios.
